# Frost-Client
A Powerful Minecraft Java Edition 1.21.1 Fabric Hack Client [Fabric API Required]

# FrostClient v3.0.1
A free Fabric hack client for Minecraft 1.21.1 with 77 modules, smooth animations, per-module keybinds and a persistent JSON config system.

# Installation
Install Fabric Loader 0.16.5+ for Minecraft 1.21.1.
Put Fabric API 0.104.0+1.21.1 into your .minecraft/mods folder.
Put FrostClient-3.0.1.jar into the same folder.
Launch the Fabric 1.21.1 profile.
# Usage
Right Shift — open / close the hack panel
Left-click a module card — toggle on / off
Right-click a module card — open settings, keybind and description
Settings are saved automatically to config/frostclient.json
# Modules
77 modules across 5 categories: Combat, Movement, Render, World and Player.

Highlights: KillAura, AimAssist, Velocity, Flight, Speed, Scaffold, ESP, XRay, Fullbright, Nuker, AutoTotem, AutoEat and many more.
